# Project architecture
- Define the site's single theme through semantic global CSS tokens and shared UI components so presentation changes do not alter business logic.
- Keep the Academy's scoped stylesheet and components independent of global presentation changes so its reference pages remain visually stable.
- Keep generated sitemap/share files, tracking, SEO and backend logic outside presentation refactors so integrations remain unchanged.
- Static public routes listed in `ROTAS_PRERENDER` (src/App.tsx), including the home, are pre-rendered post-build by `scripts/prerender.mjs` (Vite SSR of `src/entry-server.tsx`, no headless browser) into `dist/<route>/index.html`; failures fall back to SPA without failing the build. Because `dist/index.html` (home) is also the hosting fallback, the script first writes a skeleton copy for every known SPA route (fixed app routes + sitemap URLs) and the home HTML carries an inline guard that hides it on any other path. DB data used above the fold is embedded as `#dados-prerender` and seeded into React Query before mount, then refetched. Client mounts with createRoot after preloading the page module (no hydration).
